WhyCode — Finale Build Plan

Team FORTEC · Ronit Shrimankar + Udita Singh · hackFront India Grand Finale, IIIT Delhi · Build: Sat 21 Nov 14:00 → Sun 22 Nov 12:00 · Problem T1.1 — “Why The Code Is Like This” (django/django)

1Where we are

Works today (verified live, 21 Nov): ingests django/django into a graph — 678 entities, 641 edges (200 commits, 100 PRs, 100 Trac tickets, 161 files, 90 people, 27 DEPs). Answers “why is the code like this?” with a cited 2-hop evidence chain + confidence score. Refuses honestly under 4 tested rules (no terms / term in no record / confidence < 0.35 / empty chain): “Why does Django use microservices?” is refused; “Why does ignore_warnings match substrings?” is answered at 0.99 with 8 records. 13/13 tests green. Zero-dependency, runs offline from the bundled DB.

Mocked / hardcoded / missing: CLI only — no UI, no live URL. Supersession advertised but the DB holds zero real supersedes edges. Evidence chains carry noise (unrelated same-author PR; match entity listed twice). File-level entities only, no functions. Raw token-count ranking, no BM25. Snapshot data only, no refresh. No partner technology integrated. No auth. No security scan yet.

2Where we will be — by 12:00 Sun 22 Nov, all working in the live build

  • Flask web UI on a public live URL: ask a question → answer card (confidence, best match, superseded banner) → clickable evidence chain (every record links to GitHub / Trac) → interactive graph of the chain. An evaluator can use it with no one driving.
  • Real supersedes edges from DEP “Superseded by” text and “Reverts” commits; superseded decisions show a banner in the answer.
  • BM25 ranking (title weighted 2×) replacing raw token count; all 4 refusal rules untouched.
  • Evidence-chain cleanup: no authored expansion on hop 2; match entity removed from its own chain.
  • Neo4j AuraDB Free mirror of the graph, with the UI’s evidence chain served by Cypher queries — partner tech inside the core flow, not a side demo.
  • ArgosX: baseline scan by midnight tonight, final scan by 11:00 Sun, both reports + remediation log submitted.
  • Stretch, only if the above is green tree-sitter function-level entities (“why is this function like this?”); live ingest of a second repo from the UI.

4Partner technology — Neo4j

Neo4j (AuraDB Free, $0, no card). WhyCode is a knowledge graph — commits, PRs, tickets and DEPs as nodes, decisions as edges. Neo4j makes the graph itself the query engine: the UI’s evidence chain is served by Cypher, enabling GraphRAG-style retrieval in the core flow, visible in the demo. Sarvam AI does not serve the core need (Django internals are English technical docs); Arduino does not apply to a software product. SQLite stays the source of truth; Neo4j serves the live answers.
