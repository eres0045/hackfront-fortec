MCP & Decision Bridge

Model Context Protocol (MCP) ● Stdio Ready

Connect the WhyCode decision graph to Cursor, Claude Desktop, or VS Code — ask why from your editor. The server runs from this repo: python whycode_mcp.py (needs the MCP dependencies in requirements-mcp.txt).

.cursor/mcp.json 
{
  "mcpServers": {
    "whycode": {
      "command": "python",
      "args": ["whycode_mcp.py"]
    }
  }
}

For Claude Desktop, use the absolute path to whycode_mcp.py in your checkout.
